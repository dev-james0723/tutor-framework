# Licensing notes

The project metadata currently declares Apache License 2.0 (`Apache-2.0`) for the
framework code and first-party manifests. This note is an engineering record, not
legal advice; confirm the final distribution notice and any contributor agreement
before publishing a release.

Third-party skills, provider SDKs, example data and occupation source documents are
not automatically covered by the project license. Each candidate must be reviewed
for license, attribution, redistribution, privacy, data residency, account terms,
and commercial-use restrictions before adoption. Keep those decisions in the skill
adoption registry and preserve the original source reference.

Public synthetic evaluation fixtures are intentionally authored for this repository.
Do not add real user scores, customer records, patient data, case files, private
messages or unlicensed copyrighted artifacts to fixtures.
