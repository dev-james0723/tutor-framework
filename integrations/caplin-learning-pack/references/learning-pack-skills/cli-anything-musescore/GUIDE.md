# Notation-aware export reference

The source describes an optional cli-anything-musescore wrapper. It is not automatically installed by this integration. Prefer the already installed MuseScore backend and the existing Music Example Lab when they satisfy the task. Verify real command availability, source notation, exported pitch/timing and provenance; a command list is not proof of functionality.

This is a narrow Caplin integration guide. The unchanged UPSTREAM.md is a passive reference snapshot, not an automatically executed or globally authoritative skill.
